AUDITED PUBLIC BENCHMARK · 完整对照

Tender θ 与强基线：当前不是全面胜出

ASSISTments 2009 按学生 8:2 划分。同时报告 AUC 与 LogLoss，避免只展示单一有利指标。

清洗后 27.3 万条 · 4,128 名学生
模型AUC ↑LogLoss ↓结论
BKT 标准基线0.67940.5910概率校准较好
Tender θ_seq 全局初始化0.68530.6164排序接近基线，校准较弱
Tender θ_seq 文档默认 η=0.30.68951.1155不推荐作为产品默认值
Logistic 控制组0.70580.5752当前实验整体更强

结论边界：0.6895 只是 Tender 某个未校准参数配置下的 AUC 点估计；同一配置的 LogLoss 明显更差，Logistic 对照也更强。因此当前结论是“θ_seq 可用但未占优”，优先任务是参数校准、概率可信、重复划分和跨周期效果验证，而不是宣称显著领先或取代考试。

下一版基准：AUC、AUPRC、Brier、ECE、置信区间、多种子重复划分、DKT/SAKT 对照，以及次日/七日保持与支持效果。
