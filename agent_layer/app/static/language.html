LANGUAGE EVIDENCE · NOT MIND READING

一句话是证据，
不是判决

Tender 不从一句话直接判断能力、人格或疾病。它先提取可观察的语言片段，再提出多个竞争假设，最后与答题、行为、时间、真实结果和历史证据共同校准。

语言模型 / Tender 模型 / 确定性规则

语言模型做结构化抽取、语义检索、候选解释与自然表达；不能宣布知识掌握、人格、诊断或事实真相。
Tender 状态模型融合语言、行为、答题、时间、结果和历史；输出带不确定性、可更正的状态假设。
确定性规则处理高风险词路由、来源校验、置信度阈值、禁止输出和审计；不擅长反讽与复杂语境。
用户与人工复核纠正解释、确认安全、决定行动和分享范围；系统不能替代人的决定和现实保护。

明确不能从这里推出

  1. “我不行”不能推出能力低或人格缺陷。
  2. “我焦虑”不能推出焦虑障碍。
  3. “我不想学”不能推出懒惰或长期动机不足。
  4. 语言模型说“像抑郁”不能成为诊断。
  5. 一次表达不能变成永久用户标签。
