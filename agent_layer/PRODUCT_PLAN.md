# Tender 产品计划 V6

## 1. 定位

Tender 是 C 端心智化学习 App：

> 时刻记录认知与情绪状态，形成长期因果，用固定辅助 Agent 托底，并允许专家 Agent 生成、购买和出售。

## 2. 四个核心对象

| 对象 | 定义 | 产物 |
|---|---|---|
| 心智化状态 | 认知状态 + 情绪上下文 + 置信度 + 证据 | 心智化状态卡 |
| 长期因果 | 状态、支持、反思与结果的时间链 | 因果时间线 |
| 固定辅助 Agent | 始终可用的基础能力 | 连续记录、支持与安全托底 |
| 专家 Agent | 按需要生成的受控专家能力 | AgentSpec、市场授权与收入 |

## 3. 用户闭环

```text
打开 App
→ 记录此刻认知与情绪
→ 获得固定辅助 Agent 的低打扰支持
→ 需要时生成或购买专家 Agent
→ 支持后回写结果
→ 形成长期因果
→ 更新学习护照
```

## 3.1 Agent 分层

- 运行时 YAML Agent：15 个，实际可通过 `/agents/{id}/invoke` 调用；
- C 端固定辅助 Agent：5 个，是运行时 YAML 的消费者子集；
- 工作台编排 Agent：6 个，只负责多 Agent 工作台内的协作；
- MoA 路由顾问：9 个，按对话与授权摘要临时调用；
- 市场专家 Agent：动态生成，不是固定名单。

统一目录：`GET /agents/catalog`；完整代码对齐清单：`AGENT_INVENTORY.md`。

## 3.2 Agent 执行层

- `fixed_*` 与市场专家 Agent 编译为 可插拔 Agent Runtime；
- 复杂任务由 多 Agent Workflow 生成执行计划；
- 多 Agent Workflow 自动执行默认关闭；
- DAOQL 保留长期事实、因果、授权、交易与审计；
- Agent Runtime 失败时回退现有 LLM 或结构化输出。

## 4. 固定辅助 Agent

- 心智化陪伴：解释状态与卡点；
- 认知—情绪调节：调整任务粒度与恢复方式；
- 反思教练：一次一个反思问题；
- 家庭桥接：生成经授权的最小必要摘要；
- 安全与保护：后台常驻与人工升级。

固定 Agent 不依赖市场购买，始终可用。

## 5. 专家 Agent 市场

### 生成

用户输入需要后，系统生成受控 AgentSpec：

- 任务与触发；
- 输入与授权范围；
- 工具与输出 schema；
- 禁止动作；
- 评测与退出机制；
- 高风险类别认证要求。

### 出售

- 可私有保存或上架；
- 卖家设置价格；
- 平台记录版本、安全评级、授权与分成；
- 高风险类别必须认证。

### 购买

- 买家获得使用授权；
- 不转移模型权重与原始数据；
- 默认只访问授权摘要；
- 购买记录进入学习护照与审计。

## 6. 长期因果

每个时间点至少记录：

- 认知指标；
- 情绪上下文；
- 状态假设与置信度；
- 支持动作；
- 用户反思；
- 后续结果。

系统输出：

- 时间点；
- 状态变化；
- `informed_reflection`；
- `reflection_before_outcome`；
- 可审计证据引用。

因果关系是时间顺序与证据引用形成的假设，不等同于统计因果识别。

## 7. 商业模式

| 收入 | 客户 | 说明 |
|---|---|---|
| Learner Pro | 学习者 | 完整心智化反馈与学习护照 |
| Family Pro | 家庭 | 授权摘要与共同支持 |
| Advisor+ | 高需求用户 | 认证顾问与人工支持 |
| Agent 市场佣金 | 买卖双方 | 平台提供交易、授权、风控与审计 |
| Xiaomi 套餐 | 穿戴用户 | readiness 增强 |

## 8. 市场指标

- 心智化快照完成率；
- 长期因果链完整度；
- 固定 Agent 周使用率；
- 专家 Agent 生成量；
- 上架量与购买转化；
- 卖家收入与复购；
- 市场 Agent 安全评级与投诉率。

## 10. 风险与边界

| 风险 | 控制 |
|---|---|
| 状态被误当诊断 | 证据、置信度、非诊断声明与人工升级 |
| 市场 Agent 越权 | 默认摘要访问、沙箱、审计与撤回 |
| 低质量 Agent | 评测、投诉、版本回滚与下架 |
| 高风险类别 | 认证、人工审阅与保险/合规评估 |
| 家庭监控感 | 最小必要摘要，不共享原始对话 |
| 未成年人隐私 | 监护人授权、删除、导出与审计 |
