# Tender C 端心智化学习 App 架构

## 1. 总览

```text
用户交互层
  ├─ 学习者入口
  └─ 家庭入口

Agent 交互层
  ├─ 心智化学习伙伴
  ├─ 反思教练
  ├─ 对外沟通
  └─ MoA 专业顾问路由

Tender 心智层
  ├─ 知识结构
  ├─ 元认知与 JOL 偏差
  ├─ 犹豫与认知负荷
  ├─ 情绪上下文
  ├─ 节律与安排匹配
  ├─ 支持前后结果
  └─ 个体、家庭与学习共同体

DAOQL 事实层
  ├─ 学习事件
  ├─ 对话与反思
  ├─ 授权
  ├─ 因果边
  ├─ 证据引用
  └─ 审计日志
```

## 1.1 身份与对象授权

```text
签名会话（开发态 HMAC）
        ↓
Principal：actor / role / learner
        ↓
对象级授权 + 监护同意
        ↓
DAOQL 审计
```

监护关系包含申请、核验、授权、撤回和审计状态。

审计记录使用 `prev_hash + record_hash` 形成哈希链；`/audit/verify` 可检查链是否被篡改。

高风险 Agent 触发后生成安全工单，进入 `open → reviewing → escalated → closed` 流程。

生产环境将替换为 OIDC/真实登录、服务端 RBAC 和可信监护关系。

## 2. 数据流

```text
可观察行为 / 用户自述 / 授权上下文
        ↓
DAOQL 事实与因果记录
        ↓
Tender 状态估计与不确定性
        ↓
心智化状态卡
        ↓
最低必要支持
        ↓
结果验证与反思
        ↓
学习护照
```

## 3. 心智化状态卡

每张卡必须包含：

- 状态假设；
- 置信度；
- 证据引用；
- 时间戳；
- 支持建议；
- 一个反思问题；
- 非诊断边界；
- 用户纠正与撤回入口。

状态不是固定标签，而是可随时间更新的假设。

## 4. 情绪上下文

情绪推断只处理：

- 用户显式填写的效价与唤醒度；
- 用户授权文本中的情绪词；
- 与学习负载相关的上下文信号。

禁止：

- 输出人格诊断；
- 输出临床结论；
- 用单次文本给用户贴固定标签；
- 把情绪推断共享给未授权角色。

## 4.1 Agent 层级

```text
运行时 YAML Agent（15）
  └─ C 端固定辅助 Agent（5）

工作台编排 Agent（6）
  └─ 只存在于多 Agent 工作台

MoA 路由顾问（9）
  └─ 按对话和授权摘要调用

市场专家 Agent（动态）
  └─ AgentSpec 生成、购买授权、结构化调用
```

统一目录：`GET /agents/catalog`。完整对齐清单：`AGENT_INVENTORY.md`。

## 4.2 Agent 执行层

```text
Tender AgentSpec / YAML
        ↓
Agent Runtime
        ↓
工具与授权摘要
        ↓
统一结果
        ↓
DAOQL 审计
```

- 固定 Agent 和专家 Agent 都由 Agent Runtime 执行；
- 多 Agent 复杂任务使用 多 Agent Workflow；
- 多 Agent Workflow 自动执行默认关闭；
- 运行时 Memory 只作短期运行上下文，不作为永久事实库；
- 模型失败时回退现有 LLM 或结构化输出。

## 5. 专业顾问

七类专业顾问：

1. 健康
2. 营养
3. 神经认知
4. 心理支持
5. 学习科学
6. 生涯与职业
7. 安全与保护

调用原则：

- 每次 1–3 个；
- 只交换授权摘要；
- 不共享原始数据；
- 安全顾问后台常驻；
- 高风险事件转人工；
- 最终统一成一条用户体验。

## 6. 角色边界

| 角色 | 可以看见 | 不能看见 |
|---|---|---|
| 学习者 | 自己的完整记录与导出 | 他人的记录 |
| 家庭 | 经授权的最小必要摘要 | 原始对话、完整行为链 |
| 专业顾问 | 专业范围内的授权摘要 | 无关专业数据 |
| 安全支持 | 最小风险信号 | 与安全无关的原始记录 |
| 平台运营 | 聚合指标与审计 | 个体原始对话 |

## 7. 学习护照

学习护照属于学习者本人，包含：

- 学习事件与证据；
- 心智化状态变化；
- 反思与策略迁移；
- 支持前后结果；
- 可验证成果；
- 授权记录与撤回记录。

支持导出、删除和跨阶段携带。

## 8. 前端原则

- 默认只展示学习者与家庭；
- 专业顾问按需要出现，不增加用户管理负担；
- 每张状态卡必须使用“可能”“证据”“置信度”等措辞；
- 用户永远可以纠正系统判断；
- 不展示监控式家庭报告；
- 无穿戴设备不阻断核心功能。

## 9. 心智化时间线与长期因果

```text
认知 / 情绪 / 对话 / 反思 / 支持 / 结果
                ↓
        心智化快照
                ↓
        状态变化时间线
                ↓
  informed_reflection
                ↓
 reflection_before_outcome
```

每个快照包含认知指标、情绪上下文、状态假设、置信度、支持与证据引用。因果关系是时间顺序与证据引用形成的可审计假设。

## 10. Agent 经济

### 固定辅助 Agent

始终可用，不依赖购买。

### 专家 Agent

```text
需求
→ AgentSpec
→ 私有保存或上架
→ 认证与评测
→ 市场购买授权
→ 授权摘要访问
→ 结果与投诉回写
```

市场规则：

- 购买的是使用授权；
- 不转移模型权重或原始数据；
- 高风险类别需要认证与人工审阅；
- 卖家分成 80%，平台分成 20%；
- 当前支付为模拟状态，真实支付与分账待接入。

## 11. 生产前必须补齐

- 服务端 RBAC；
- 真实登录与监护人授权；
- 数据保留与删除任务；
- Agent 版本与回滚；
- 高风险事件人工值班；
- 固定评测集与漂移监控；
- 可穿戴数据正式合作协议。

## 世界树投影

```text
DAOQL 客观事件根系
→ Bloch 有限接触面
→ Agent Bridge 树干
→ 输入 / 记忆 / 调节 / 整合反思 / 表达五类树枝
→ 11 个体验节点与局部状态轴
→ 开花事件与结果回流
```

八功能态度决定内部世界入口，大五脉搏提供近期心理资源与人际支持。世界树由 `/world-tree/{student_id}` 投影生成；共享枝默认不生成，必须获得双方授权。该投影不是脑区诊断、量子脑证据或关系匹配评分。
