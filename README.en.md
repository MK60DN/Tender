# Tender Research & Modeling

This repository contains Tender whitepapers, research reports, reproducible experiments, knowledge databases and reference model code.

The runnable product, UI, Agent runtime, desktop overlay, teaching website, manuals and deployment configuration live in:

https://github.com/MK60DN/Tender-Product

Start with:

- docs/whitepaper/
- docs/research/
- experiments/
- knowledge_data/
- modeling/

Validation:

    python scripts/verify_research.py

Synthetic and benchmark results are not evidence of real-world educational efficacy. Language evidence does not determine mastery, personality or clinical state.
