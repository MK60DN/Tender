# Modeling / 建模参考实现

This directory contains the canonical reference modeling code extracted during the repository split at Tender commit e917545.

## Scope

- Tender state and longitudinal models;
- preassessment and world setup;
- predictive-processing and mentalization signals;
- world tree and golden-bias regulation;
- cognitive constructs and neuro-learning evidence;
- knowledge forest and knowledge context;
- language evidence;
- mechanism design, benchmark and decision loop;
- retrieval and advisor routing.

## Important boundary

These modules are reference implementations, not a standalone application. The runnable product, APIs, UI, Agent runtime, desktop overlay, website and deployment configuration live in:

https://github.com/MK60DN/Tender-Product
