# Tender 神经学习证据与数据源 V1.0

## 从语言 Agent 到可验证的学习行为与神经科学证据层

版本：1.0  
日期：2026-10-29  
定位：研究目录、数据源评估、模型边界与实验设计  
性质：研究性证据汇编，不构成医学或心理诊断

---

## 摘要

Tender 当前的主体是：

- 自然语言对话；
- 多 Agent 路由；
- 学习行为事件；
- 规则与知识追踪；
- 用户授权后的行动与结果记录。

它不是运行时脑解码系统，也不是神经影像模型。

这个判断需要明确写出来。否则，产品很容易把“心智化”“神经科学”“多 Agent”包装成一个听起来先进、但无法被科学验证的整体。

正确的补强方式不是给语言模型套上一层脑区术语，而是建立三层证据结构：

```text
公开研究与公共数据
→ 校准构念、阈值、实验设计和偏差边界
→ 设计用户授权的行为弱先验
→ 用真实行动结果验证帮助是否有效
```

本文收录：

- 5 个学习行为数据源；
- 8 个神经发育、影像或神经数据共享资源；
- 12 条与研究构念直接相关的论文；
- 阶段化产品映射；
- 5 组可执行实验；
- 明确的禁止性主张。

## 一、先审计 Tender 现在到底是什么模型

| 层次 | 当前能力 | 证据来源 | 不能声称的能力 |
|---|---|---|---|
| 语言层 | 自然语言理解与生成 | 大模型、对话历史 | 不等于理解大脑 |
| Agent 层 | Triage、功能型 Agent、专家协作 | 路由规则与提示约束 | 不等于专家议会 |
| 行为层 | 触发、回复、反馈、行动、结果 | DAOQL 事件 | 不等于神经测量 |
| 推理层 | 规则、知识追踪、风险规则 | 可控模型与实验 | 不等于因果诊断 |
| 神经层 | 当前无运行时神经解码 | 公开研究仅作离线校准 | 不能读脑 |
| 治理层 | 链下专家议会 | 实名签署、申诉与复核 | 当前不上链 |

因此，对外更准确的表述是：

> Tender 用语言、行为和历史结果推断“可能影响行动的因素”，并用结果检验推断；它不是直接从大脑读取状态。

## 二、三层神经学习证据架构

### 2.1 第一层：离线研究校准

用途：

- 确定哪些构念有可靠研究支持；
- 明确哪些构念只是假说；
- 校准量表、特征和实验指标；
- 发现年龄、文化、临床与样本偏差；
- 为专家议会提供可质证的研究依据。

这一层可以使用公共研究数据，但不接触 Tender 用户个人数据。

### 2.2 第二层：运行时行为弱先验

Tender 在用户授权后观察：

- 任务启动延迟；
- 任务切换频率；
- 停留与恢复；
- 错误重复；
- 自评情绪；
- 行动是否完成；
- 可选的睡眠与活动摘要。

这些信号只能生成“竞争假设”：

```text
更像工作记忆过载
更像任务启动阻力
更像知识缺口
更像焦虑或威胁评估
更像睡眠和疲劳影响
也可能只是环境干扰
```

每个假设都必须带置信度、证据范围和可更正入口。

### 2.3 第三层：神经科学只做验证与边界

脑影像、EEG 和神经队列适合：

- 研究构念效度；
- 校准发育阶段差异；
- 做独立复制；
- 检查产品机制是否与已知认知过程冲突。

不适合：

- 给单个用户贴脑区或疾病标签；
- 从点击、心率或睡眠推断具体神经机制；
- 用脑图做营销装饰；
- 用相关性替代教育效果。

## 三、研究证据如何映射到产品

| 构念 | 研究结论的使用方式 | Tender 中的产品动作 | 禁止过度解释 |
|---|---|---|---|
| 认知负荷 | 工作记忆资源有限，减少无关负荷 | 任务拆解、减少干扰、最小下一步 | 不能靠点击测出认知负荷数值 |
| 工作记忆 | 容量有限，信息保持受注意约束 | 单轮少信息、外部记忆、及时提示 | 不能承诺万能记忆扩容 |
| 执行功能 | 抑制、工作记忆、认知灵活性影响行动 | 启动、切换、计划、复盘支持 | 不能由日志直接诊断执行功能 |
| 检索练习 | 主动提取促进长期保持 | 复述、自测、检索任务 | 不能替代理解与迁移 |
| 间隔练习 | 分散练习通常优于集中练习 | 动态复习间隔与遗忘风险 | 不存在万能固定间隔 |
| 睡眠与活动 | 与健康和教育结果存在关联 | 恢复提示、负荷上下文 | 关联不等于个体因果 |
| 青少年发育 | 奖赏、社会情绪与控制发展不同步 | 自主支持、情绪调节、同伴情境 | 不能用单一脑成熟时间表标签化 |
| 反馈与预测误差 | 预期与实际差异驱动学习调整 | 预测—行动—结果—更新 | 不能把学习简化成奖赏回路 |
| 认知训练 | 迁移到一般认知的证据有限 | 做任务支持而非脑力训练承诺 | 不承诺提高智商或注意力 |
| 学习风格 | 匹配视觉/听觉/动觉缺乏可靠证据 | 用真实效果选择策略 | 不把 MBTI 或风格当神经诊断 |

### 3.1 三条研究结论尤其重要

第一，工作记忆有限。  
Tender 应该减少信息搬运，而不是不断生成更多建议。

第二，主动提取和间隔练习比重复阅读更可靠。  
这比“AI 自动生成课件”更接近真实学习机制。

第三，神经科学进入教育最容易犯的错误，是把复杂脑过程压缩成漂亮但错误的标签。  
因此，产品必须把神经科学当作约束和证据，而不是 UI 装饰。

## 四、核心研究证据

### 4.1 认知负荷与工作记忆

Sweller 的认知负荷研究指出，问题解决会竞争有限的工作记忆资源，教学设计需要减少无关负荷。  
Cowan 的工作记忆研究进一步说明，注意控制与短时存储容量都高度有限。

产品含义：

- 一次只给一个最小行动；
- 长答案必须压缩成可行动步骤；
- 不把“多看内容”当作学习；
- 用外部记录替代持续心算。

限制：

- 不能从点击次数计算工作记忆容量；
- 不能把工作记忆训练包装成一般智力提升。

### 4.2 执行功能

Diamond 将执行功能概括为抑制、工作记忆和认知灵活性。它们影响任务启动、规则切换、计划与复盘。

产品含义：

- 把“拖延”拆成启动、选择、保持和恢复问题；
- 遇到卡点时给出具体第一步；
- 在用户恢复后撤掉脚手架，避免依赖。

限制：

- 执行功能不是单一分数；
- 行为日志只能支持假设，不能诊断 ADHD 或其他疾病。

### 4.3 检索练习与间隔练习

Roediger 与 Karpicke 的研究表明，主动测试比重复阅读更有利于长期保持。  
Cepeda 等人的元分析表明，分散练习通常优于集中练习。

产品含义：

- 用复述、自测和间隔复习代替“再看一遍”；
- 用真实结果调整复习间隔；
- 把错误当作下一次提取训练的信号。

限制：

- 最佳间隔随材料与目标变化；
- 需要理解、反馈和迁移任务配合。

### 4.4 睡眠、活动与反馈

2022 年系统综述显示，睡眠、久坐和身体活动与儿童青少年健康及教育结果相关。  
预测误差研究说明，结果偏离预期时，反馈可以驱动陈述性学习调整。

产品含义：

- 睡眠和活动只作为恢复与负荷的上下文；
- 每次建议都记录预测、行动和结果；
- 结果不符时更新建议，而不是坚持原判断。

限制：

- 关联不是个体因果；
- 可穿戴设备的信号可能受佩戴、疾病、情绪和情境影响；
- 不能用“多巴胺”解释全部学习行为。

### 4.5 神经神话与认知训练边界

Howard-Jones 提醒，神经科学进入教育必须警惕过度简化、脑区标签和商业化神经神话。  
认知训练综述指出，训练通常产生任务特异性提升，向一般认知能力迁移的证据有限。

产品含义：

- 不做“提高智商”“激活大脑”“左右脑开发”；
- 不以脑科学术语替代效果证据；
- 用真实迁移任务验证训练是否有效。

## 五、学习行为数据库

| 数据源 | 主要信号 | 适用阶段 | 访问方式 | Tender 用途 |
|---|---|---|---|---|
| ASSISTments / PSLC DataShop | 作答、正确率、提示、响应时间 | 初中、高中、大学 | 注册使用 | 知识追踪与错误模式 |
| EdNet | 作答序列、题目与讲座元数据 | 初中、高中 | 公开下载，核对条款 | 会话级行为建模 |
| OULAD | VLE 点击、作业、成绩、退课 | 大学、就业 | 开放，核对许可 | 成人学习与风险基准 |
| StudentLife | 手机行为、EMA、学业结果 | 大学 | 研究协议 | 低打扰信号与隐私边界 |
| KDD Cup 2010 | Tutor 日志、技能标签、正确性 | 初中、高中、大学 | 注册使用 | 知识追踪对照 |

这些数据库能回答：

- 学习行为是否可以预测下一次表现；
- 哪些行为特征真的与结果相关；
- 模型跨数据集是否稳定；
- 会话粒度是否优于单题粒度。

它们不能回答：

- 用户此刻的脑状态；
- 某个具体脑区是否激活；
- 一个学生是否患有某种神经发育障碍；
- 学习建议是否造成因果效果。

PSLC DataShop、ASSISTments、EdNet、OULAD 和 KDD Cup 都是行为层资源。它们的价值在于建立可重复的知识追踪与行动结果基准，而不是制造神经科学叙事。

## 六、神经发育与影像资源

| 数据源 | 主要信号 | 适用阶段 | 访问方式 | 正确用途 |
|---|---|---|---|---|
| ABCD Study | MRI、认知、心理健康、环境 | 初中、高中、大学 | NDA 受控访问 | 发育先验与构念验证 |
| Healthy Brain Network | MRI、EEG、认知、学习与心理表型 | 小学、初中、高中 | 数据使用协议 | 学习障碍与跨诊断研究 |
| NKI-Rockland | MRI、认知、生活方式、发育 | 全生命周期 | 数据使用协议 | 阶段差异与生命周期先验 |
| Human Connectome Project | 任务 fMRI、认知任务、行为 | 大学、就业 | 开放数据使用条款 | 成人认知功能验证 |
| 学龄儿童算术纵向 fMRI | 算术任务、纵向脑与行为 | 小学、初中 | 论文与数据仓库条款 | 学习相关神经变化研究 |
| 中国学龄人群神经发育资源 | MRI、认知、环境 | 小学、初中、高中 | 按论文数据协议 | 中国样本先验与偏差检查 |
| OpenNeuro | MRI、EEG、MEG、PET | 全生命周期 | 数据集各异 | 发现与复制研究 |
| NeuroVault | 统计脑图、图谱元数据 | 非阶段特定 | 开放 | 元分析与先验对照 |

### 6.1 这些资源能做什么

- 检查某个构念是否有跨样本证据；
- 比较不同年龄阶段的先验差异；
- 设计更合理的认知任务；
- 验证行为特征是否与神经科学文献冲突；
- 为专家议会提供可引用的研究依据。

### 6.2 这些资源不能做什么

- 把群体统计结果直接套到单个用户；
- 用脑影像给用户贴“注意力差”“自控力弱”的标签；
- 把研究数据接入日常推荐系统；
- 把神经相关误写成神经因果；
- 在没有新实验的情况下承诺教育效果。

### 6.3 数据接入原则

```text
研究数据与研究用户分离
公开队列与个人数据分离
离线校准与运行时推断分离
相关证据与因果结论分离
模型建议与临床诊断分离
```

所有受控数据都需要：

- 数据使用协议；
- 最小必要字段；
- 去标识化；
- 访问审计；
- 禁止再识别；
- 不向产品端回传个体级神经数据。

## 七、按学习阶段映射

| 阶段 | 神经与行为重点 | Tender 可观察信号 | 产品动作 | 不应做什么 |
|---|---|---|---|---|
| 小学 | 执行功能发展、外部脚手架、共同调节 | 启动延迟、任务完成、成人反馈、睡眠 | 短任务、可视化步骤、成人协同提示 | 不给儿童贴脑或疾病标签 |
| 初中 | 奖赏与社会敏感性、自主需求、睡眠相位变化 | 回避、切换、自评、同伴情境 | 自主支持、失败后重启、沟通脚本 | 不用连续刺激制造依赖 |
| 高中 | 高负荷、压力、睡眠不足、策略需求 | 恢复时间、错误重复、任务堆积 | 卡点分诊、最小计划、检索与间隔复习 | 不承诺考试提分或治愈焦虑 |
| 大学 | 自主管理、复杂项目、身份探索 | 启动、拖延、求助、跨课程规划 | 项目拆解、复盘、长期证据 | 不把点击当认知能力 |
| 就业 | 注意力碎片化、迁移、身份威胁 | 学习—工作冲突、任务完成、迁移结果 | 工作场景练习、反馈闭环、职业路径 | 不强行设计家长监控端 |

### 7.1 对产品架构的直接结论

Tender 的长期架构可以覆盖终身学习，但模型必须先承认：

- 小学阶段更依赖成人共同调节；
- 初中阶段更依赖自主支持与情绪安全；
- 高中阶段更依赖压力下的执行支持；
- 大学阶段更依赖自主计划与身份探索；
- 就业阶段更依赖真实任务迁移。

一把尺子无法量完整个生命周期。

## 八、Tender 应该怎么做实验

### E-N1：任务拆解是否降低负荷

- A 组：完整任务说明；
- B 组：三步拆解；
- C 组：Tender 根据状态只给一个最小步骤；
- 指标：任务启动延迟、完成率、主观负荷、放弃率；
- 注意：主观负荷不能用点击替代。

### E-N2：检索与间隔是否优于重复阅读

- A 组：重复阅读；
- B 组：自测；
- C 组：自测 + 自适应间隔；
- 指标：延迟后保持、迁移题表现、错误复发；
- 这是教育效果实验，不是神经影像实验。

### E-N3：睡眠与活动上下文是否有增量

- A 组：仅学习行为；
- B 组：学习行为 + 睡眠/活动摘要；
- 指标：模型校准、提示被采纳率、行动恢复率；
- 结论标准：只有增量稳定且没有标签伤害，才保留该上下文。

### E-N4：预测—行动—结果反馈是否改善下一次判断

- 记录系统对任务完成概率的预测；
- 记录用户行动与实际结果；
- 比较是否使用预测误差更新建议；
- 指标：预测校准、下一步准确率、用户纠正率。

### E-N5：研究先验是否真的帮助产品

- 从 HBN、ABCD、NKI 等资源提取群体先验；
- 与 Tender 自身行为数据做一致性检查；
- 不把个体放进公共神经数据模型；
- 只检验构念方向、阶段差异和偏差，不检验“读脑”。

## 九、允许与禁止的主张

| 主张 | 是否允许 | 正确表述 |
|---|---|---|
| 研究先验 | 允许 | “基于工作记忆和认知负荷研究，我们采用任务拆解” |
| 行为弱信号 | 允许 | “当前行为更像任务启动阻力，置信度中等” |
| 多假设输出 | 允许 | “可能存在知识缺口、疲劳或焦虑，需要进一步验证” |
| 直接读脑 | 禁止 | 当前没有运行时神经解码能力 |
| 点击诊断 | 禁止 | 点击不能诊断认知或心理疾病 |
| 学习风格匹配 | 禁止 | 视觉/听觉/动觉匹配缺乏可靠证据 |
| 脑力训练迁移 | 禁止 | 不能承诺提高一般智力或注意力 |
| MBTI 神经诊断 | 禁止 | MBTI 可作为沟通偏好，不是神经科学证据 |

### 9.1 对外可用的一句话

> Tender 以认知负荷、执行功能、检索练习、间隔练习和反馈研究作为设计约束，用授权后的行为与真实结果验证帮助；当前不从脑影像或点击直接读取个体心智。

- 数据集数量与研究数量；
- 行为与脑数据的分离；
- 当前模型边界；
- 运行时神经推断关闭状态。

### 10.3 运行原则

```text
公共研究数据不进入个人推荐
受控神经数据不回传产品端
用户行为数据不冒充神经测量
每条判断都有来源、时间和置信度
高风险行为进入人工安全流程
```

截至 2026-10-29，目录、边界、筛选和接口测试已纳入全量 55 项自动测试。

## 十二、结论

Tender 目前主要是语言与行为模型，这个定位不需要回避。

真正有价值的升级不是把语言模型硬叫成神经模型，而是：

```text
用神经科学与学习研究约束产品规则
用行为数据生成可更正的状态假设
用真实结果检验帮助是否有效
用专家议会处理证据冲突
用链下治理保护隐私和申诉
```

这四件事连起来，才是 Tender 的“心智化”能力。  
单独一个大模型、单独一个脑影像数据集、单独一个 BFT 都不能构成这套能力。
