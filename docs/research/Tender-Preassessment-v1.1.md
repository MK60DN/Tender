# Tender 首次预检测 V1.1

## 大五人格、MBTI 沟通偏好与荣格八维探索性筛查

版本：1.1  
日期：2026-10-29  
定位：首次使用画像、支持方式校准与 Agent 初始组合  
性质：自我反思工具，不是诊断、能力测试或人格判决

---

## 摘要

Tender 的首次预检测不是为了回答“你是什么人”，而是为了回答四个产品问题：

1. 你通常怎样启动和完成任务？
2. 什么条件最容易让你卡住或耗竭？
3. 哪种沟通方式更容易被你接受？
4. 第一次使用时，哪些支持可能更适合你？

预检测包含三层：

```text
20 道大五人格
→ 稳定行动倾向与支持需求

8 道 MBTI 沟通偏好
→ 信息、决策、互动和计划偏好

8 道荣格八维探索题
→ 认知模式的初步假设
```

大五人格是核心；MBTI 和荣格八维是可选、探索性部分。三者都不能决定用户能力、价值、职业命运或资源分配。

产品输出使用：

- 可能的长处；
- 容易卡住的条件；
- 支持偏好；
- 初始 Agent 组合；
- 置信范围与用户确认入口。

产品不输出：

- 缺陷；
- 能力排名；
- 临床诊断；
- 不可更改的人格类型；
- “你只能做什么”的职业判决。

## 一、为什么以大五人格为核心

大五人格采用五个连续维度：

| 维度 | 产品含义 |
|---|---|
| 开放性 | 对新方法、抽象联系和探索的偏好 |
| 尽责性 | 计划、秩序、坚持与收尾倾向 |
| 外向性 | 社交能量、主动表达和外部刺激偏好 |
| 宜人性 | 合作、共情、冲突与边界方式 |
| 情绪稳定性 | 压力恢复、威胁敏感和情绪波动倾向 |

Tender 使用自评分数和区间，不使用人群百分位。当前版本没有建立代表性常模，因此不能声称“你超过了多少人”。

大五维度更适合作为连续的支持假设：

- 高尽责性可能带来计划能力，也可能在计划被打断时产生自责；
- 低尽责性可能保留灵活性，也可能让任务启动和收尾更耗力；
- 高开放性可能带来探索能力，也可能因选项过多而发散；
- 低外向性可能带来深度专注，也可能让主动求助更耗能。

同一维度没有绝对好坏。

## 二、MBTI 如何使用

MBTI 在 Tender 中只作为沟通偏好：

```text
E / I：互动与恢复偏好
S / N：具体信息与整体框架偏好
T / F：逻辑标准与关系影响偏好
J / P：计划确定与开放调整偏好
```

8 道双极题目产生四个连续分数。

输出规则：

- 分数接近中间时输出 `X`；
- 因此可能出现 `ENFJ`、`INXJ`、`XXXX` 等代码；
- 代码只用于调整信息呈现、沟通节奏和反馈方式；
- 不输出“适合职业”“智商”“能力上限”“关系命运”。

Tender 不把 MBTI 称为神经科学测量。它可以作为自我反思和沟通框架，但不能替代人格研究、能力测评或临床评估。

## 三、荣格八维如何使用

当前版本纳入八个功能偏好：

| 功能 | 当前含义 |
|---|---|
| Ne 外倾直觉 | 联想、新可能性和快速探索 |
| Ni 内倾直觉 | 信息收束、长期方向和整体洞察 |
| Se 外倾感觉 | 对当下环境和具体变化的反应 |
| Si 内倾感觉 | 过去经验、细节和稳定流程 |
| Te 外倾思维 | 目标、效率、标准和结果组织 |
| Ti 内倾思维 | 概念一致性和内部逻辑校验 |
| Fe 外倾情感 | 群体气氛、关系和合作协调 |
| Fi 内倾情感 | 个人价值、真实感受和边界 |

当前八维采用每题一个功能的探索性筛查，因此：

- 只输出 `top_functions` 和 `less_preferred`；
- 置信度标记为 `exploratory_low`；
- 不输出功能百分比、大脑使用率或能力排名；
- 后续版本需要增加每个功能的题目数量并做信度验证。

八维结果的产品用途：

- 帮助用户理解自己更自然地使用哪种信息加工方式；
- 调整 Agent 的解释顺序；
- 帮助复盘“为什么某种学习方式对我更耗能”；
- 产生可讨论的假设，而不是固定标签。

## 四、计分方式

### 4.1 标准化

每个题目按 1–5 分计分：

```text
normalized = (raw - 1) / 4
```

反向题先转换：

```text
reverse_raw = 6 - raw
```

每个维度取题目的平均值，范围 0–1。

当前区间：

```text
score < 0.40      lower
0.40 ≤ score ≤ 0.60  balanced
score > 0.60      higher
```

这些区间只用于产品内部的支持假设，不是心理测量常模。

### 4.2 MBTI 轴

每轴由两道双极题组成，分数表示更接近高分端：

```text
axis_score = mean((raw - 1) / 4)
```

当前偏好规则：

```text
axis_score > 0.55  → 高分端
axis_score < 0.45  → 低分端
0.45–0.55          → X，表示接近中间
```

`confidence = |axis_score - 0.5| × 2` 只表示距离中间的程度，不表示心理测量信度。

### 4.3 荣格八维

当前采用一个功能一题的探索性分数：

```text
function_score = (raw - 1) / 4
```

输出：

- 分数最高的三个功能；
- 分数最低的两个功能；
- 置信级别固定为 `exploratory_low`；
- 不进行跨用户百分位比较。

## 五、产品输出

预检测生成以下字段：

```text
big_five
mbti_preference
jungian_functions
strength_hypotheses
friction_hypotheses
support_preferences
agent_routing_hypotheses
confidence
user_review_required
diagnosis = false
```

### 5.1 可能的长处

示例：

- 尽责性偏高：计划、拆解和持续完成；
- 开放性偏高：探索、联想和新方法尝试；
- 外向性偏低：独立思考、深度专注和观察；
- 情绪稳定性偏低：敏感、风险觉察和共情。

### 5.2 容易卡住的条件

示例：

- 尽责性偏高且计划被打断：可能过度自责或追求完美；
- 开放性偏高且选项过多：可能发散或偏离目标；
- 外向性偏低且需要临场求助：可能更耗能；
- 情绪稳定性偏低且面对批评：可能占用较多认知资源。

这里输出的是条件，不是人的缺陷。

### 5.3 支持偏好

根据大五、MBTI 与八维组合生成：

- 先文字还是先对话；
- 先例子还是先框架；
- 先逻辑还是先回应感受；
- 给清单还是给开放选项；
- 提供多少探索空间；
- 何时撤掉脚手架。

### 5.4 初始 Agent 组合

只作为建议：

- 尽责性偏低：学习策略师、元认知教练；
- 情绪稳定性偏低：心理调节师；
- 开放性偏高：生涯规划师；
- 内倾思维靠前：学科专家。

用户可以在 Agent 圆桌中删除、替换或关闭任何建议。


## 五点五 注意力成本与认知矫正

“长处”在本产品中不是固定能力，而是：

> 某类任务更容易捕获注意、维持投入并从中断中恢复。

“短处”不是缺陷，而是：

> 在某些条件下，维持同一任务需要更高注意成本，或更容易被特定线索带走。

因此预检测在人格结果之外增加：

```text
attention_profile
cognitive_correction_plan
```

### 注意力成本画像

| 维度 | 产品问题 |
|---|---|
| 捕获 capture | 什么最容易让用户开始投入？ |
| 维持 sustain | 什么条件能让投入持续？ |
| 泄漏 leakage | 注意最容易被什么打断？ |
| 恢复 recovery | 中断后什么方式最容易回来？ |
| 脚手架 scaffolds | 哪些外部结构能降低注意成本？ |

典型组合：

- 开放性偏高 + 尽责性偏低：新想法容易带走注意，主任务留下开放循环；
- 宜人性偏高：照顾他人需求可能切碎自己的任务时间；
- 情绪稳定性偏低：评价和不确定性更容易抢占注意；
- 外向性偏低：高频社交和临场表达可能额外消耗注意；
- 生活方式偏 P：开放选项过多时缺少任务闭合。

### 认知矫正练习卡

每一张练习卡包含：

```text
pattern_hypothesis
trigger
correction_practice
success_evidence
fade_rule
boundary
safe_exit
```

示例：

| 模式假设 | 替代练习 | 有效证据 |
|---|---|---|
| 新颖刺激转移 | 保留一个主任务，新想法先进入停车区，完成一个 15 分钟步骤后再决定是否切换 | 主任务恢复或完成一个可交付步骤 |
| 过度迁就打断 | 先确认当前任务和可承诺时间，再回应他人请求 | 保住一段完整任务时间并清楚表达边界 |
| 威胁监测 | 写下担心的具体结果、证据和一个最小行动，行动后更新判断 | 焦虑没有完全消失，但能开始并完成下一步 |
| 反复检查 | 开始前定义“足够好”，设置一次复核上限和停止时间 | 在标准时间内提交或关闭任务 |
| 分析瘫痪 | 写出当前最佳解释和一个可证伪行动，用小实验替代继续分析 | 完成一次行动并根据结果修改模型 |

### 矫正边界

- 矫正的是策略、环境和反馈，不是人的价值；
- 每次只练一个模式，避免同时改造自己；
- 连续两次成功后逐步减少提示；
- 用户可拒绝、暂停或删除任何练习；
- 若持续造成显著痛苦、功能受损或安全风险，应停止自助练习并寻求专业支持；
- 这不是注意力训练、ADHD 治疗或临床认知矫正。

## 六、首次体验

预检测页面：

```text
/ui/preassessment.html
```

流程：

```text
阅读用途与边界
→ 勾选显式同意
→ 20 道大五人格
→ 可选 8 道 MBTI
```

界面一次只显示一道题，减少信息负荷；可以返回上一题；大五部分必须完成，MBTI 和八维可以跳过；草稿只保存在本地浏览器。

## 七、数据与隐私

默认保存：

- Big Five 标准化分数；
- MBTI 轴分数和偏好代码；
- Jungian 功能分数；
- 支持假设；
- 问卷版本、时间和事件 ID。

默认不保存：

- 逐题原始回答；
- 页面停留时间；
- 键盘输入；
- 与人格无关的私人对话。

事件记录：

```text
event_type = preassessment_profile
source = self_report_preassessment
raw_responses_stored = false
```

提交需要：

- 明确同意；
- 学习者身份；
- 对象级授权；
- 可重测和撤回。

## 八、验证计划

当前预检测是产品原型，不是已验证量表。

### V1：重测稳定性

- 同一用户间隔 2–4 周重测；
- 检查 Big Five 各维度相关；
- 检查 MBTI 轴稳定性和 `X` 比例；
- 检查 Jungian 功能排序稳定性。

### V2：内部一致性

- 对 Big Five 每个维度计算 Cronbach α 或 McDonald ω；
- 低于可接受阈值的维度必须修改或增加题目；
- Jungian 单题筛查不宣称高信度。

### V3：聚合效度

- 与公版 IPIP 大五量表对照；
- 检查维度相关方向和强度；
- 不与受版权保护量表做未经许可的商业复制。

### V4：产品增量

- A 组：无预检测；
- B 组：仅 Big Five；
- C 组：Big Five + MBTI；
- D 组：Big Five + MBTI + Jungian；
- 指标：首次行动恢复率、提示接受率、误打扰率、主观理解度、7 日留存；
- 如果 C/D 只增加用户负担而不增加行动恢复，默认只保留 Big Five。

### V5：用户解释

- 用户是否认为画像“有帮助但不过度定义我”；
- 是否能修改、拒绝或删除每个假设；
- 是否出现自我标签、宿命感或依赖；
- 是否增加对 Agent 的信任而不增加盲从。

## 九、禁止事项

- 不用人格分数决定是否能使用 Tender；
- 不用人格分数定价或排序；
- 不把 MBTI 当招聘、升学或临床依据；
- 不把荣格八维当能力排名；
- 不向家长、老师或机构展示未经用户授权的完整画像；

- 不把“低尽责性”写成“懒惰”；
- 不把“高情绪敏感性”写成“脆弱”。

## 十一、研究边界

### 大五人格

大五人格是当前较稳定的五因素描述框架，但自评仍受情境、样本、文化和自我认识影响。Tender 当前使用自编短题，必须经过独立信效度验证后才能称为标准化量表。

### MBTI

MBTI 更适合作为沟通和自我反思框架。Tender 不把它作为神经科学、能力、职业或临床证据。

### 荣格八维

荣格八维具有文化和社群意义，但当前版本只有一个功能一道题，不能支持强结论。它的产品地位是“可选探索”，不是核心预测变量。

### 产品原则

> 人格结果只改变帮助方式，不改变用户被尊重的程度，也不改变用户获得资源的资格。

## 十二、结论

第一次预检测应该快速、克制、可撤回：

```text
大五人格
→ 了解稳定行动倾向

MBTI
→ 调整沟通和信息呈现

荣格八维
→ 生成探索性的认知偏好假设

真实行动与结果
→ 最终决定哪些假设值得保留
```

Tender 不是通过一次测试定义一个人，而是通过一次自评提出几个可验证的支持假设，再让真实使用结果逐步修正它们。注意力成本与认知矫正也不是给用户贴标签，而是把“我哪里不行”改写为“在哪种条件下，我需要什么脚手架，以及如何验证它有效”。
