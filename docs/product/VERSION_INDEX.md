## 版本规则

- 活动目录只保留当前正式版本，避免用户同时看到多套互相矛盾的说明。
- 历史版本只保留在 Git 标签和 `CHANGELOG.md` 中。
- v1.6.0 是清理前快照；v1.6.1 是只保留当前正式文档的整理版。
- 任何新版本发布时，应替换当前文件，而不是并列堆积旧文件。

## 当前实现事实

- 全量自动测试基线：93 项通过。
- 教学网站：9 个中英双语模块，不包含公式。
- 治理：链下专家议会；BFT 与链上写入默认关闭。
- 神经数据仅用于离线校准，运行时神经推断关闭。
- 个人学习护照与机构业务数据分账；机构购买系统不等于拥有学习者全部心智数据。
