# 你的数据为什么必须能带走：数字主权与新数字经济学

传统教育软件最容易被忽略的问题是：你的学习数据到底属于谁？

平台可能保存了你的作业、对话、错题、情绪记录和成长轨迹。但当你离开时，这些数据能不能带走？谁能继续使用？产生价值以后，你能否知道价值去了哪里？

如果这些问题没有答案，所谓“个性化学习”就可能变成新的数据锁定。

## 数字主权不是把数据锁起来

数字主权不是说数据永远不动，而是说用户拥有一组可执行的权利：

- 可以带走；
- 可以撤回授权；
- 可以限制用途和期限；
- 可以知道谁在使用；
- 可以更正错误；
- 可以退出而不失去自己的成长证据。

这和“平台施舍你一个导出按钮”不同。主权必须被写进系统结构，而不是写在宣传页上。

## 使用权比所有权更现实

很多数据不是“卖给谁”就结束了。

更合理的方式是：在特定目的、特定期限、特定范围内授予使用权。

例如，学生可以授权某个机构使用自己的学习证据来提供反馈，但这份授权不应自动变成广告、转售或永久买断。

## 价值怎么回流

如果数据被用于创造商业价值，贡献者应该有透明的回流机制：

- 贡献记录可以被审计；
- 使用范围可以被追踪；
- 收益分配可以被申诉；
- 公共数据池可以服务公共利益；
- 法币和合同仍是现实结算基础。

这不是承诺每个人马上“靠数据分红”。它首先是一套机制要求：不能一边使用用户贡献，一边让用户完全不知道价值如何产生和分配。

## 终身认知学籍

Tender 用“终身认知学籍”描述一种产品方向：

学习者拥有可携带、可验证、可更正的学习轨迹和成长证据。

它不是官方学历，也不能保证雇主或学校采纳。它的意义是：你不需要每次换机构都从零证明自己。

## B 端不能用数据锁定学生

过去一些教育机构会把“学生带不走历史资产”当成壁垒。

从数字主权角度看，这是矛盾的。真正可持续的 B 端价值，不是扣押数据，而是：

- 教学质量；
- 审计能力；
- 持续支持；
- 可信凭证；
- 对学生成长的长期理解。

数据可以带走，信任才留得下。

## 它不是什么

贡献积分不是投资品，不是可炒作代币，也不承诺升值。链上记录不等于事实正确。任何自动化分配都必须可追溯、可隔离、可停止。

数字主权也不是“所有数据都必须公开”。隐私、最小化和目的限制仍然是底线。

## 你可以怎么用

选择学习产品时，问五个问题：

1. 我的数据能导出吗？
2. 我能撤回哪一部分授权？
3. 谁能看到我的数据？
4. 出错时谁能更正？
5. 我退出后，学习记录还属于我吗？

数据像水，不是因为它应该免费，而是因为它必须有边界地流动、被净化，并最终回到贡献者。
