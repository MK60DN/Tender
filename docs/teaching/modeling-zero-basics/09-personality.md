# MBTI、荣格八维与大五：Tender 怎样使用它们

用户第一次进入 Tender 时，系统需要知道从哪里开始理解他的世界。

有人更容易从外部互动中获得线索，有人更习惯先在心里整理；有人先看事实，有人先看可能性；有人先检查逻辑，有人先感受关系。这些偏好会影响学习入口，也会影响人与世界、人与人之间的协作方式。

人格测评在这里提供早期线索。它们帮助系统选择起点，之后仍要由真实行动不断校正。

## 为什么要先认识起点

每个人的主观世界和客观世界都不一样。

同样是学习一门课，有人需要先看到完整框架，有人需要先做一道具体题；有人在群体讨论中想得更快，有人独处时才形成观点；有人需要明确规则才安心，有人需要空间探索才有动力。

如果系统从完全相同的入口要求所有人，很多差异会被误认为能力问题。

Tender 的预评估先收集偏好线索，再据此安排更合适的观察方式。用户看到的是可调整的建议，不需要先接受一个固定类型。

## MBTI 先看两种态度

在 Tender 的产品语言里，内向与外向描述注意和能量的常见方向。

外向更容易从外部互动、行动和即时反馈中获得线索；内向更容易从内部整理、反思和稳定空间中形成判断。两者都可以在不同场景里切换，也会随任务和关系变化。

两种方向各有优势，也不会直接决定一个人适合什么职业或怎样生活。

## 再展开四种功能

荣格的传统里，四种功能分别是感觉、直觉、思考和情感。

- 感觉关注具体事实、细节和当下经验；
- 直觉关注可能性、模式和未来方向；
- 思考关注逻辑、规则和一致性；
- 情感关注价值、关系和人的感受。

Tender 严格把两种态度与四种功能组合起来，形成八种功能—态度视角，用更细的结构理解整个人。

| 功能—态度 | 常见关注点 |
|---|---|
| 外倾感觉 | 眼前事实、环境变化、可操作细节 |
| 内倾感觉 | 身体记忆、熟悉经验、细微差别 |
| 外倾直觉 | 外部机会、联想、可能性探索 |
| 内倾直觉 | 内部意象、长期模式、深层方向 |
| 外倾思考 | 外部规则、结构、可验证逻辑 |
| 内倾思考 | 原理一致、独立分析、深层推理 |
| 外倾情感 | 群体氛围、关系协调、共同价值 |
| 内倾情感 | 个人价值、真诚、内在一致 |

同一功能朝向外部或内部时，表现会很不一样。Tender 保留这八种视角，是为了更细地理解一个人怎样接触世界。

## 统一做题，保留每条轴的确定度

即使用户已经知道自己的四个字母，Tender 仍会让所有人做同一套短测评。

原因很简单：人对每条轴的确定度常常不同。有人很确定自己喜欢独处，却说不清自己更依赖事实还是可能性；有人熟悉 MBTI 标签，却没有区分过外倾思考和内倾思考。

系统记录每条轴的倾向和不确定程度。确定度低时，系统先保留这个空白，再用后续行为继续观察。

## 大五人格负责连续基线与稳定性

大五人格提供另一类信息：开放性、尽责性、外向性、宜人性、情绪稳定性。

它用连续维度描述倾向，更适合观察一个人在时间中的稳定性和变化。Tender 用它辅助人与人之间的互动建模，例如：

- 对方需要更多结构，还是更多探索空间；
- 压力下更容易出现哪种反应；
- 冲突之后需要多快恢复；
- 什么沟通方式更容易被接住。

大五不替代 MBTI 的结构入口，也不替用户决定关系。它提供的是一层长期、连续的背景。

## 结果怎样进入世界建模

人格线索最后会进入两类世界。

客观世界从学校、年级、专业、课程、任务和环境开始。系统据此确定当前学习场景，再观察真实表现。

主观世界从用户的兴趣、价值、知识连接、反馈方式和生命树开始。系统据此选择更合适的提问与行动起点。

用户最终看到的，是一组可以修改的起点建议：先从哪里学、用什么方式表达、遇到卡点时怎样求助。MBTI、荣格八维和大五在后台协作，前台始终服务于用户当前的生活。
