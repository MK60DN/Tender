# Agent 不是一个“全能AI”：它更像被授权的岗位

一提到 Agent，很多人会想象一个无所不知的助手：什么都能回答，什么都能操作。

但真正进入学习和生活场景后，一个“全能 AI”反而很危险。因为它可能越过权限、混淆证据、替人做决定，最后还无法解释为什么。

Tender 的 Agent 建模，更接近“岗位”而不是“神”。

## 每个 Agent 都要有职责边界

一个可审计的 Agent，至少要回答：

- 它负责什么任务？
- 可以访问哪些数据？
- 可以调用哪些工具？
- 禁止做什么？
- 必须引用什么证据？
- 什么时候需要停下来找人类？

比如，学习策略师负责拆解任务，不等于可以诊断学习障碍；心理调节师可以提供支持，不等于可以做临床诊断；安全保护官可以升级风险，不等于可以替代真实世界求助。

## Agent Bridge：把事件翻译成体验

生命树的树干是 Agent Bridge。

它的工作不是“替用户决定”，而是把客观事件翻译成可讨论的体验假设：

- 这次停顿更像任务启动困难，还是知识缺口？
- 这次回避更像害怕评价，还是疲劳？
- 这次求助更适合给提示，还是先回应情绪？

Bridge 的关键，是把“发生了什么”与“可能意味着什么”连接起来，同时标出证据和不确定性。

## 为什么需要多个 Agent

同一个问题，可以从不同角度理解。

一个学生说“我不想学了”，可能需要：

- 学习策略师：把任务缩小；
- 神经认知师：检查注意和工作记忆负荷；
- 心理调节师：看看是否存在威胁或羞耻；
- 生涯规划师：检查目标是否仍然属于自己；
- 安全保护官：确认是否存在高风险。

这比让一个 Agent 同时扮演所有角色更可控，因为每个视角都有独立边界，也更容易被审计。

## Persona 只是表达方式

Tender 里可以有不同人格化 Agent，有的温和，有的直接，有的像教练，有的像顾问。

但 Persona 不应改变证据阈值和安全规则。换一种说话方式，不等于换一套事实标准。

## 人类保留最终权力

Agent 可以提出建议、准备草稿、检查目标，但高风险动作必须有人类审批。自动消息不应默认发送，涉及隐私和资源分配的动作必须可停止、可回滚。

## 它不是什么

Agent 不是数字人格，不是无限权限的自动化系统，也不是“Agent 越多越智能”。

没有规格、证据、版本和权限的 Agent，只是更复杂的自动回复。

## 你可以怎么用

遇到一个 AI 建议时，问四个问题：

- 它现在扮演什么角色？
- 它用了什么证据？
- 它有没有越权？
- 最后决定的人是谁？

好的 Agent，不是替你做主，而是让你更有能力做主。
