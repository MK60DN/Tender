## 这套课解决什么问题

很多人听到“预测加工、心智化、生命树、布洛赫球、DAOQL、Agent、黄金比、知识森林”时，会以为这是很多互不相关的概念。

这套课把它们串成一条完整链路：

```text
世界发生事件
→ DAOQL 保存客观证据
→ 有限观测形成局部状态
→ Agent Bridge 翻译成体验假设
→ 生命树组织成长
→ 行动进入世界
→ 结果回流并更新模型
```

每一篇都从熟悉的场景开始，用日常语言解释模型的含义，不要求数学、编程或心理学基础。

## 阅读顺序

推荐按 01 → 12 顺序读。先看建模与学习基础（01–03），再看产品结构与 Agent（04–07），最后看人格、行动与治理（08–12）。

每篇正文约 1,200–1,800 字，标题和摘要写在 Markdown front matter 里，正文按自然阅读节奏分段，可直接复制使用。

## 阅读说明

这套课面向日常理解，帮助读者把模型用在学习、沟通和产品设计里。

涉及心理状态的内容用于支持和沟通；需要诊断或治疗时，请寻求专业帮助。人格测评用于选择建模起点，不参与能力评价。生命树、布洛赫球和黄金比是建模语言，用来组织观察与行动。数据经济部分讨论治理机制，涉及投资的决定请咨询专业人士。
