# 微信公众号发布流程

## 发布前准备

1. 登录微信公众号后台。
2. 新建图文消息。
3. 从对应 Markdown 文件中复制正文，不复制 YAML front matter。
4. 标题使用 `wechat_title`；摘要使用 `summary`；封面按 `cover_idea` 制作。
5. 发布前通读全文，确认事实、数字和语气自然。

## 公众号排版建议

- 一级标题保留为文章标题，不再重复正文 H1。
- 每 300–500 字插入一个小标题或分隔线。
- 按正文的自然叙述排版，不需要额外加入固定提示框或重复声明。
- 每篇结尾可以放下一篇预告，但不要制造焦虑式追更。
- 图片优先使用抽象星系、树、网络、局部球面、证据链等视觉，不使用脑区诊断图。
- 不在图片或正文中展示真实用户对话、学生身份、健康数据或未脱敏截图。

## 发布状态

所有文章当前状态为 `draft`。只有在公众号后台完成人工预览和最终确认后，才改为 `published` 并记录发布日期。
