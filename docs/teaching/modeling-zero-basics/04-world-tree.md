# 生命树不是脑解剖图：它是一套成长语法

“生命树”听起来很浪漫，但它首先需要回答一个问题：

这棵树到底在表示什么？

在 Tender 里，生命树不是对大脑结构的解剖，也不是说人的心智真长成一棵树。它是一套帮助我们整理成长过程的语法。

## 树根：客观世界留在地下的证据

树根对应 DAOQL 中的客观事件。

一次作答、一段对话、一次请求帮助、一次任务完成、一次失败反馈，都是发生过的事件。它们带有来源、时间、关系、版本和权限。

根的意义不是“隐藏”，而是：树冠上的一切判断，都要能回到地下的证据。

如果根没有记录，叶子上的结论就很容易变成漂亮但没有依据的故事。

## 树干：把事件翻译成体验

同一个事件，对不同的人可能有不同含义。

老师只是提问，一个学生可能感到被支持，另一个学生可能感到被审视。事件是客观的，体验需要解释。

树干就是 Agent Bridge。它把客观事件翻译成可讨论、可修正的主观体验假设：

- 这更像任务启动阻力，还是知识缺口？
- 这更像疲劳，还是害怕评价？
- 这更像需要帮助，还是需要更多自主空间？

桥梁的作用不是替人决定，而是把“发生了什么”连接到“这对你意味着什么”。

## 树冠：不同的认知功能

树冠可以理解为多组功能分支：注意、记忆、语言、内省、情绪、身体和行动阻力。

注意分支关注什么东西更容易被抓走；
记忆分支关注信息能否保持和提取；
语言分支关注一个人如何表达不确定性、回避和求助；
内省分支关注他如何预测自己的表现；
情绪和身体分支关注当下负荷与恢复条件。

它们不是彼此孤立的标签，而是共同影响一个行动能否发生。

## 开花：把内部生长带到世界

学习是树吸收、整合和长出结构；创造是开花。

表达、提问、教学别人、协作、试验、发表作品，都是开花。开花意味着你不再只在内部理解，而是把理解交给世界检验。

## 结果：世界给出的反馈

结果可能是作品、分数、反馈、机会、关系变化、失败，也可能是新问题。

结果不是给树贴价值的标签。它更像环境反馈：哪些枝条有生命力，哪些地方需要修剪，哪些方向值得继续生长。

## 一条完整链路

一个学生做题失败，不是只看“分数低”：

1. 客观事件：作答、错误、停顿、是否求助；
2. 体验假设：可能是知识缺口，也可能是评价压力；
3. 树冠功能：注意、情绪、记忆和自我预测如何参与；
4. 开花：尝试讲出思路或换一道题；
5. 结果：反馈让假设更新；
6. 再回到根系。

这就是从世界到体验、再回到世界的生长链。

## 它不是什么

生命树不是脑区定位图，不是人格测试，也不是“你的人生已经注定长成什么样”。

它不证明某个人一定适合某个职业，也不替代教师、家长或临床判断。

## 你可以怎么用

下次复盘一次失败时，不要只写“我不行”，试着写：

- 发生了什么事实？
- 我当时怎么解释？
- 哪个功能被卡住了？
- 我做了一个什么行动？
- 世界给了什么结果？

把评价改成生长链，问题才有下一步。
