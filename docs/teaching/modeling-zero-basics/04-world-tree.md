# 生命树：把成长看成一套结构

一棵树会从环境里吸收水分和养分，也会长出新的枝条、花和果。

人的成长也有相似的节奏：我们从外界学习结构，再把学到的东西重新组合，最后带着自己的选择回到世界。Tender 借用树的形状，把这条路径放在同一张图上。

## 一棵树怎样长大

树根向下寻找水和矿物，树干把养分送到枝冠，枝条在不同方向展开，花把内部状态带到外界，果实承接一次生长周期的结果。

这套结构很有用，因为它同时容纳了三件事：

- 什么在支撑成长；
- 成长往哪些方向分化；
- 一次创造怎样回到环境并获得反馈。

在 Tender 里，这棵树是一张会随时间和行动变化的工作图。

## 树根：让事实有出处

树根对应 DAOQL，也就是客观事件与证据层。

一次作答、一段对话、一次求助、一次完成、一次退出，都可以成为事件。事件带上时间、来源、关系和权限后，才有资格进入后续模型。

根扎得稳，树冠才有条件自由生长。这里的“稳”，让每个重要判断都能回到证据，同时给生长留下空间。

## 树干：把事件翻译成体验

树干是 Agent Bridge。

它把外部发生的事翻译成可以讨论的体验假设：这次停顿更像任务启动困难，还是知识缺口？这次回避更像害怕评价，还是身体疲劳？这次求助更适合先给提示，还是先回应情绪？

Bridge 连接了“发生了什么”和“可能意味着什么”，同时保留不确定性。

## 枝与冠：形成功能分支

树枝代表不同的功能方向。感知与判断、内向与外向、接近与回避、探索与稳定，都可以成为树上的分支。

树冠则是一个人的认知结构、知识连接和当前可用的行动方式。它会随季节变化，也会因为新经验长出新的枝。

学习更像根系吸收和枝叶修剪：外面的结构进入内部，旧结构被重新整理。一个人学得越多，树冠通常越丰富，但也越需要修剪，避免所有枝条争抢同一束光。

## 开花：把内部结构带到世界

开花是创造开始显形的时刻。

一个想法被写成文章，一个理解被讲给别人，一个方案被做成原型，一次协作被组织起来。花把树内部的状态带到外部，让原本只存在于个人心智里的结构，进入别人可以看见、回应和使用的空间。

创造需要根系积累的证据，也需要枝条已经形成的连接。

## 结果：让反馈回到树根

果实是行动之后的结果。

它可能是一篇作品、一项能力、一次合作，也可能是一次失败。结果会回到系统里，成为下一轮建模的证据：哪些方法有效，哪些枝条需要继续生长，哪些结构需要修剪。

学习从外向内吸收，创造从内向外显化，结果再把外部反馈带回内部。生命树的价值，就在于让这三个方向连成循环。
