# 白皮书 V2.2 增补章：多模态有限观测

## 为什么需要新的观测层

V2.1 主要依靠事件、语言、作答、反馈和授权行为摘要。它们足以支持预测加工与心智化建模，却无法回答一个具体问题：当学习者说“我卡在这里”时，“这里”究竟是什么？

应用类别、窗口标题和答案正确性都不等于情境。V2.2 增加两类本地能力：经用户逐次授权读取当前可见顶层窗口，以及对用户主动选择的图片、音频和视频执行本地 OCR、语音转写和关键帧分析。

这不是无限监控，而是有限观测面的扩展。

## MCP 作为可审计工具层

本地 MCP 把能力拆成明确工具：授权、状态、读取、截图和撤销。每次授权默认 15 分钟；撤销后下一次读取立即失败。媒体工具要求用户先选择文件并显式确认本地处理。

关键不是“工具能调用多少系统能力”，而是权限、范围和失败状态能否被看见、测试和撤回。

## 客观内容、派生信号与主观解释

界面和媒体原文只在本机内存中存在。进入规划层的是应用类别、任务关键词、窗口数量、文字可用性和媒体处理状态，而不是整段正文。

Tender 可以知道“用户正在看高考报名页面且页面包含缴费提示”，却不能在缺少其他证据时推断用户焦虑。Tender 可以知道“用户打开了一份讲义”，却不能仅凭 OCR 结果断言用户理解了概念。

## 精度与误差

新增观测进入预测误差框架时必须重新加权。权限越敏感、来源越不稳定、OCR 越不可靠，其精度权重应越低。受保护窗口、空白截图、隐藏标签页和密码字段属于缺失数据，不是负证据。

拒绝授权也不能被解释为隐瞒。拒绝只意味着该证据不可用。

## 可检验假设

- H13：界面上下文比仅使用应用类别更能减少高考报名任务中的无效提示；
- H14：用户选择的讲义图片经 OCR 后，卡点定位准确率高于仅凭用户复述；
- H15：视频关键帧文字与音轨转写同时可用时，网课任务理解优于任一单一模态；
- H16：15 分钟授权与立即停止机制提高接受度，而不显著增加无必要授权；
- H17：只发送派生信号与发送整段原文相比，提示质量相近而隐私风险显著降低；
- H18：视觉模式的上传提示降低误触率，但可能降低使用率，需要权衡。

这些假设尚待真实任务和预注册实验验证。当前实现只证明工程链路可运行，不证明教育效果。

## 边界

界面读取只覆盖当前桌面可见顶层窗口，不覆盖隐藏标签页、密码字段、剪贴板、摄像头、麦克风、键盘记录、其他账户桌面和受保护内容。媒体插件只处理用户主动选择的文件。

视觉模式是否上传取决于用户配置的提供方；本地 OCR 模式不上传。原文、截图和媒体内容不写入 DAOQL。

V2.2 的核心不是“能读更多”，而是“读到的内容如何被限制、派生、纠错，并最终回到用户的行动与结果”。
