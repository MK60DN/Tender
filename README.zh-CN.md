# Tender 研究与建模仓库

本仓库只保留 Tender 的白皮书、研究报告、可复现实验、知识数据库与参考模型代码。

可运行产品、UI、Agent 运行时、桌面弹层、教学网站、产品与用户手册、部署配置已迁至：

https://github.com/MK60DN/Tender-Product

主要入口：

- docs/whitepaper/
- docs/research/
- experiments/
- knowledge_data/
- modeling/

校验方式：

    python scripts/verify_research.py

合成实验和公开基准不等于真实教育效果。语言证据不能单独决定掌握度、人格或临床状态。
